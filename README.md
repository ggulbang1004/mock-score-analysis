# 모의고사 성적 분석

성적통지표 PDF를 올리면 원점수가 포함된 분석 엑셀을 만들어 주는 웹 앱입니다.

## 입력

- 학생별 성적통지표 PDF (각 학생 2쪽: 성적표 + 해설)
- 반별 PDF를 **모두** 올리면 전교 석차가 맞게 계산됩니다.
  (예: 2-1.pdf, 2-2.pdf, … 2-10.pdf)

## 출력 (엑셀, 3개 시트)

- **반별**: 반/번호 순. 과목별 원점수·표준점수·백분위·등급 + 표준점수 합 + 전교 석차
- **석차별**: 전교 석차 순 (동점자 동일 석차)
- **등급별 비율**: 과목별 1~9등급 인원·비율

원본 파일(2026_10__2.xlsx)과 같은 서식(맑은 고딕, 과목별 색상, 테두리)에
원점수 열을 추가했습니다.

## 실행 방법

### Streamlit Cloud (권장 — 설치 없이 브라우저에서 사용)

1. 이 폴더 내용을 GitHub 저장소에 올립니다.
2. [Streamlit Cloud](https://share.streamlit.io/)에서 저장소를 연결합니다.
3. Main file: `app.py`

### 로컬 실행

```
pip install -r requirements.txt
streamlit run app.py
```

## 검증

- 2026년 10월 고2 전국연합학력평가 2-1반 PDF(26명)로 테스트
- 표준점수/백분위/등급 390개 항목을 원본 엑셀과 전수 대조 → 오류 0개
- 전교 석차는 올린 PDF 전체를 기준으로 계산됩니다 (1개 반만 올리면 그 반 안에서만 석차 계산)
